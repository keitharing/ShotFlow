ShotFlow 사용 안내

AI 영상 샷의 버전 관리 · 자동 검수 · 리뷰 · 편집 조립 · ComfyUI 생성과 수정 · 납품을 한곳에서 하는 로컬 툴

설치와 실행

처음 한 번설치.cmd 더블클릭. 이 폴더 안에만 설치합니다 (Python 3.10+, Node.js 20+ 필요). 약 1~2분.
매번시작.cmd 더블클릭 → 브라우저에서 http://127.0.0.1:8710이 열립니다. 검은 창을 닫으면 종료됩니다.
생성 기능왼쪽 아래 ComfyUI 시작을 누릅니다 (처음 약 30초). 다 쓰면 전원 버튼으로 끕니다. 밤새 켜 두지 마세요.
모든 데이터는 data 폴더에 저장됩니다 (DB, 프록시, 생성 결과, 납품). 원본 영상과 기록 파일은 읽기만 합니다. 서버는 이 PC 안(127.0.0.1)에서만 열립니다.

화면 구성

현황판승인 현황, 검수 오류·경고 수, 로컬 생성 통계(레시피별 작업 수·평균 시간), 최근 작업과 활동
시퀀스샷 목록(현재 승인 버전, 상태, 검수 결과)과 편집본 목록
샷버전 계보(생성 → 수정 → 등록), 프레임 단위 플레이어, 자동 검수, 리뷰 노트, 생성 기록, 이 샷의 생성 작업
생성레시피 선택 → 입력 → 변형 그리드 → 결과 격자에서 버전 등록
작업 대기열모든 생성 작업의 상태·시간·VRAM·온도. 작업을 누르면 실행된 노드 구조가 보입니다
레시피레시피 버전 기록, 화면에 노출되는 입력, 필요한 모델, 노드 구조
납품 패키지승인 버전을 이름 규칙대로 모으고 체크섬으로 검증

리뷰

  1. 샷 화면에서 버전을 고르고 재생합니다. 플레이어 아래 막대의 색 표시는 검수 문제 구간입니다 (누르면 그 프레임으로 이동).
  2. 리뷰 노트에 코멘트를 쓰고 승인 / 수정요청 / 반려를 누릅니다. "현재 프레임에 고정"을 켜면 프레임 번호가 함께 남습니다.
  3. 승인은 샷당 하나입니다. 새 버전을 승인하면 이전 승인 버전은 "검토중"으로 돌아갑니다.
  4. 승인 버전과 비교를 누르면 리뷰 화면에서 두 버전을 좌우 또는 와이프로 비교합니다. Space 재생, ← → 한 프레임 이동.

플레이어는 음소거 상태로 불러오고, 재생할 때 소리가 켜집니다 (오른쪽 아래 소리 버튼).

편집본 조립

  1. 시퀀스 화면 → 편집본을 엽니다. 새로 시작하려면 이름을 쓰고 복제 (각 샷의 현재 승인 버전으로 채워짐).
  2. 표에서 샷 순서, 사용 구간(시작·끝 프레임), 전환(컷 / 디졸브), 밝기를 고칩니다. 위쪽 타임라인에 바로 반영됩니다.
  3. 자동 밝기 맞춤: 기준 샷의 밝기 쪽으로 각 샷을 절반만큼(최대 ±0.04) 맞춥니다.
  4. 마감에서 페이드와 엔드카드를 정하고 조립 실행. 저장 → 조립 → 새 버전 등록 → 자동 검수 → 컷 경계 비교 시트가 한 번에 진행됩니다.
  5. 이전 편집본과 비교로 리뷰합니다. 편집 결정은 edits 폴더의 JSON으로도 재현할 수 있습니다 (shotflow apply-edl).

생성 (ComfyUI)

  1. ComfyUI를 시작합니다 (왼쪽 아래).
  2. 샷 화면의 이 버전으로 생성 또는 왼쪽 메뉴의 생성으로 들어갑니다.
  3. 레시피를 고르면 입력칸이 자동으로 만들어집니다 (레시피 노드 중 제목이 SF:로 시작하는 것). 원본이 필요한 레시피는 원본 버전과 프레임을 고릅니다.
  4. 변형 그리드: 시드를 쉼표로 여러 개, 강도도 여러 개 넣으면 조합만큼 만들어집니다 (최대 12개).
  5. 결과 격자에서 마음에 드는 것만 버전으로 등록합니다. 등록된 버전은 자동 검수됩니다.

부분 수정

  1. 샷 화면에서 고칠 프레임에 멈추고 부분 수정을 누릅니다.
  2. 붓으로 고칠 부분을 칠합니다 (크기 조절, 지우개, 모두 지우기).
  3. 수정 지시(프롬프트), 피할 것, 강도, 후보 수(1~4)를 정하고 후보 만들기.
  4. 후보는 원본의 자식 버전(예: v01_f60_fix_a)으로 자동 등록됩니다. 리뷰 화면에서 원본과 비교해 승인하세요.
칠한 영역 주변만 잘라 SD1.5로 다시 그리고 원래 프레임에 붙입니다. 칠하지 않은 픽셀은 바뀌지 않으며, 자동 검수의 "마스크 밖 변경 0px" 항목이 매번 이를 확인합니다. 결과는 정지 이미지입니다 (영상 전체 수정은 아님).

ComfyUI 화면에서 ShotFlow 노드 쓰기

  1. ShotFlow와 ComfyUI(ShotFlow에서 시작)를 켠 상태에서 브라우저로 http://127.0.0.1:8190을 엽니다.
  2. 캔버스를 더블클릭해 ShotFlow를 검색합니다.
    • ShotFlow 버전 불러오기: 목록에서 버전을 고르고 프레임 번호를 넣으면 그 프레임이 IMAGE로 나옵니다. version_id 출력도 있습니다.
    • ShotFlow에 등록: IMAGE를 연결하고 샷을 고르면 실행할 때 ShotFlow에 새 버전(pub_001 …)으로 등록됩니다. parent_version_id에 불러오기 노드의 version_id를 연결하면 계보가 이어집니다.
  3. 등록된 버전에는 실행된 노드 구조와 ComfyUI 화면용 워크플로(workflow.json)가 함께 저장되어 나중에 같은 구성을 다시 열 수 있습니다.

이 노드는 ComfyUI 폴더에 설치하지 않습니다. ShotFlow가 ComfyUI를 켤 때 integrations\comfyui\shotflow_nodes만 골라 불러옵니다. ShotFlow 서버가 꺼져 있으면 목록 대신 번호를 직접 입력하는 칸이 나옵니다.

3D 연동 (Blender)

왼쪽 메뉴 3D 연동. Blender 4.2 LTS가 C:\Program Files\Blender Foundation에 있으면 바로 씁니다 (다른 곳이면 환경 변수 SHOTFLOW_BLENDER에 blender.exe 위치). ShotFlow는 Blender를 화면 없이 초기 설정으로 실행하므로, 평소 쓰는 Blender 설정과 .blend 파일은 바뀌지 않습니다.

3D 키프레임 — Blender로 구도를 잡고 AI가 사진처럼 그리기

  1. 장면 고르기: 예시 장면을 누르거나 "Blender 파일 선택"으로 .blend를 고릅니다. 처음 여는 파일은 카메라·프레임·해상도를 확인하는 데 10~40초 걸립니다.
  2. 깊이 이미지 만들기: 붙일 샷과 프레임을 고르고 누르면 일반 렌더·깊이(가까울수록 밝게)·마스크가 나옵니다. 일반 렌더는 그 샷의 버전(b3d_001 …)이 됩니다.
  3. AI로 그리기: 무엇을 그릴지(영어) 적고, "구도 고정"(높을수록 Blender 구도 그대로)과 "새로 그리는 정도"(낮을수록 Blender 렌더에 가깝게)를 고른 뒤 몇 장 그릴지 정합니다. 한 장에 약 1분이고, 연속으로 그릴 때는 GPU가 60°C 이하로 식은 뒤 다음 장을 시작합니다. 마음에 드는 결과에서 "버전으로 등록" (g3d_001 …).
  4. 영상으로 만들기: 등록한 키프레임과 움직임 프롬프트로 Seedance 패키지를 만듭니다 (아래 "외부 생성").

비·효과 레이어 합성

  1. 레이어 렌더: 투명 배경으로 효과만 렌더할 장면을 고르고 프레임 범위를 정합니다. 물체 뒤로 가려져야 할 부분은 Blender에서 대리 물체에 Holdout 재질을 씁니다 (예시 rain_layer_r05 참고).
  2. 합성할 샷과 진하기: 샷과 영상 버전을 고르고 "빛 더하기"(비·불꽃처럼 밝게만) 또는 "일반"을 고릅니다. 슬라이더를 움직이면 원본과 합성 미리보기가 나란히 바뀝니다.
  3. 합성 만들기: 전체 프레임을 합성해 자식 버전(v01_comp_001 …)으로 등록하고 자동 검수합니다. 원본 영상과 소리는 그대로입니다. "원본과 비교"로 리뷰 화면을 엽니다.

외부 생성 (Seedance)

ShotFlow는 로그인·업로드·결제를 하지 않습니다. 패키지를 만들면 data\external\job번호에 시작 프레임(1920×1080), 프롬프트, 설정, 안내가 저장됩니다. Higgsfield에서 직접 생성한 뒤, 받은 영상을 같은 화면에 끌어다 놓고 차감된 크레딧을 적으면 시작 프레임의 자식 버전(sd_001 …)으로 등록되고 현황판 크레딧 합계에 더해집니다.

내 Blender 파일을 쓸 때

  • 활성 카메라가 있어야 합니다 (장면 속성 › 카메라).
  • 마스크가 필요한 물체는 SF_MASK라는 컬렉션에 넣습니다. 없으면 마스크는 만들지 않습니다.
  • 예시 장면은 scenes\perfume_rain\build_scenes.py로 다시 만들 수 있습니다.

새 레시피 추가

  1. ComfyUI에서 워크플로를 만들고 API 형식으로 저장합니다.
  2. 화면에 보여 줄 입력이 있는 노드의 제목을 SF:이름으로 바꿉니다 (예: SF:프롬프트, SF:샘플러). 결과를 저장하는 SaveImage 노드는 SF:출력.
  3. recipes\새이름\ 폴더에 api.json과 recipe.json을 넣습니다. 기존 레시피 폴더를 복사해 고치는 것이 가장 빠릅니다.
  4. 레시피 화면의 recipes 폴더 다시 읽기를 누릅니다. 파일이 바뀌면 새 버전으로 등록되고, 지난 작업은 당시 버전을 그대로 가리킵니다.
recipe.json 항목의미
output결과 노드 제목과 종류 (image 또는 영상 프레임 frames + fps)
expose노드별로 보여 줄 입력 이름 목록 (생략하면 그 노드의 값 입력 전부)
bindings원본 프레임·구간처럼 ShotFlow가 채워 넣는 입력
strength_input변형 그리드의 "강도"가 바꿀 입력
size_inputs, limits메모리 부족 시 줄일 해상도, 이 PC에서 허용하는 크기·프레임 수

납품

  1. 납품 패키지 화면에서 이름과 대상(승인된 샷 버전 / 승인된 편집본), 시퀀스를 고르고 패키지 만들기.
  2. data\deliveries\이름_시각\에 {project}_{sequence}_{shot}_{version} 이름으로 복사되고, manifest.json(생성·검수 요약), manifest.csv(엑셀용), checksums.sha256이 함께 생깁니다.
  3. 체크섬 다시 확인으로 파일이 빠지거나 바뀌지 않았는지 검증합니다 (기록에 없는 파일도 알려 줌).

승인되지 않은 버전은 납품할 수 없습니다. 편집본을 납품하려면 먼저 리뷰에서 승인하세요.

문제 해결

증상확인할 것
ComfyUI가 시작되지 않음data\comfy\logs의 최신 로그. 다른 ComfyUI(예: E:\AI_제작환경\시작.cmd, 8188)가 켜져 있으면 끄고 다시 시도하세요. GPU를 나눠 쓰면 메모리가 부족합니다.
작업이 "실패: GPU 보호 기준 초과"온도·VRAM·RAM 기준에 걸린 것입니다. 몇 분 쉬었다가 해상도를 낮춰 다시 실행하세요.
작업이 "중단됨"작업 중 서버가 꺼진 경우입니다. 생성 화면에서 다시 요청하세요.
영상이 "불러오는 중"에서 멈춤처음 여는 버전은 브라우저용 사본(프록시)을 만드는 데 몇 초 걸립니다. 새로고침하세요.
3D 연동에서 "카메라가 없습니다"Blender에서 카메라를 추가하고 장면 속성의 카메라로 지정한 뒤 저장하세요.
3D 작업이 "GPU 식히는 중"에서 오래 멈춤GPU가 60°C 이하로 내려가야 시작합니다 (최대 10분). 노트북 통풍을 확인하세요. 10분이 지나면 그대로 시작하고, 83°C에 닿으면 중단됩니다.
노드 목록이 번호 입력칸으로 나옴ComfyUI가 노드 정보를 읽을 때 ShotFlow 서버가 꺼져 있었습니다. ShotFlow를 켠 뒤 ComfyUI 화면을 새로고침하세요.
