다시 찍는 법 (원본 DB를 건드리지 않음)
1. 원본 data\shotflow.db 를 data_demo\shotflow.db 로 복사 (sqlite backup). data_demo\imports, deliveries, generated, comfy 는 지우고
   data\comfy\launch_options.json · object_info_snapshot.json 을 data_demo\comfy 로 복사 (시연 중 ComfyUI를 켜기 때문)
2. backend 폴더에서:  set SHOTFLOW_DATA=..\data_demo  →  ..\.venv\Scripts\python.exe -m shotflow serve --port 8720
   (8710은 원본 데이터 서버 포트라 피함)
3. 이 폴더에서:  ..\..\.venv\Scripts\python.exe record_demo.py test   (장면마다 정지 그림 → test\)
                ..\..\.venv\Scripts\python.exe record_demo.py video  (영상 → out\)
